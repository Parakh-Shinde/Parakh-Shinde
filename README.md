### AST Auditor — Python Static Analysis
A lightweight static analysis tool that uses Python's Abstract Syntax Tree (AST) to identify potentially unsafe dynamic code execution patterns.

- Detects calls to `eval()` and `exec()` using syntax-aware analysis.
- Produces findings with rule identifiers, severity, and source locations.
- Supports command-line usage and JSON-formatted output.
- Includes automated tests for detection behavior, safe cases, and syntax errors.

**Technologies:** Python · AST · pytest · Ruff · Static Analysis
