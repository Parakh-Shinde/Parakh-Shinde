# 💫 About Me

Aspiring SOC Analyst transitioning from a 3-year career in technical support into Security Operations. CEH and CHFI certified, with hands-on lab experience in SIEM detection engineering, cloud security monitoring, and incident response.

**Hands-on lab experience:** Built and documented detection rules across Splunk SPL, Sigma, and Elastic KQL — covering reconnaissance, credential abuse, privilege escalation, SQL injection, and cloud API misuse — mapped to MITRE ATT&CK. Deployed a production-style SOC monitoring lab integrating Splunk, Sysmon, and Suricata across network, endpoint, and cloud telemetry. Simulated ransomware and network intrusion scenarios to practice detection and incident-response workflows end to end. Separately built an AWS cloud security monitoring environment using CloudTrail, GuardDuty, and VPC Flow Logs.

**Professional foundation:** 3 years administering 50+ Windows/Linux systems in an enterprise environment — resolving 200+ incidents annually at 95% SLA compliance, managing Active Directory, and using Wireshark and TCP/IP diagnostics for root-cause troubleshooting.

**Certifications:** CEH and CHFI (APC Hacking University, Bangalore). Currently completing an Advanced Cybersecurity Program with IIT Guwahati (via AccioJob), alongside an MCA in Cyber Security & Cyber Forensics at SRM Institute of Science and Technology, Chennai.

**Target roles:** SOC Analyst (L1), Junior Security Analyst, SIEM Analyst, or Cloud Security Analyst.

📫 Open to connecting with anyone hiring for entry-level security roles or building strong SOC/detection teams.
